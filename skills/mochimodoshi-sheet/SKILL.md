# mochimodoshi-sheet — 持ち戻し依頼 指示書

受取拒否になったゆうパックについて、スタッフが**郵便局へ電話をかけるだけ**で済む指示書を A4・1枚 PDF で作る
(2026-11-06 運用者決定。#320・注文 10015290 で確立)。手順欄は無い。電話で言う内容は「配達を中止してください。中止して、当社へ返送してください。」と言い切る(「どう手続きすればよいか」とは聞かない)。

## 手順

1. **追跡で現在の状況を調べる**(読み取りだけ・秘匿なし)。`https://trackings.post.japanpost.jp/services/srv/search/direct?reqCodeNo1=<番号ハイフン無し>&locale=ja` の表から、
   商品種別(代金引換か)・配達予定局・最新の履歴(持ち戻りの日と局)を取る。引受局(差し出した局)が「電話する先」。
2. **差し出した局の電話番号**は運用者に確かめる(呉郵便局=0570-943-916。2026-11-06 運用者提供)。荷物がある局の番号は日本郵便の局検索ページ(公式)で確かめる。
3. 次を実行する。引数は `--help` 参照。

```bash
python C:/ClaudeCode/.claude/skills/mochimodoshi-sheet/make_sheet.py --inquiry-no 2560-9255-8761 --order-no seifukunofuji-10015290 --ship-date 2026-11-02 --to-name "西村 和幸" --to-addr "〒096-0063 北海道名寄市緑丘9番地53" --product-type "代金引換ゆうパック(代引まとめ)・サイズ80" --status "11/4 ご不在のため持ち戻り(名寄郵便局で保管中) / お客様は受取を拒否" --holding-office "名寄郵便局(北海道名寄市・配達予定局)" --holding-note "参考: 代表 0570-943-581 / 集荷 0800-0800-111" --out <出力先>.pdf
```

4. 出力が「OK … (1ページ)」であること、PDF を画像にして見た目(下端の記録欄・フッターが切れていないか)を確かめる。
5. 運用者に見せて OK をもらってから、**頼まれたときだけ**標準プリンターで印刷する(`stock-alert/print_pages.ps1`。PDF は PyMuPDF で PNG 化)。
6. 完成した PDF は `C:\Users\user\Downloads\` と NAS `\\192.168.1.50\共有スペース\寺下\999.一時ファイル` の両方へ置く。

## 注意
- 記録欄(電話した日時・対応者・結果・見込み・手数料・メモ)は既定で付く。不要なら `--no-record`。
- 代金引換のときは商品種別に必ず入れる(代金は受け取っていない)。
- お客様の氏名・住所を含むので、用が済んだら処分するよう PDF のフッターに書いてある。電話番号は載せない。
- 日本郵便の相談センターは「取戻し請求は窓口のみ(本人確認書類が必要)」と案内している。電話で受けてもらえない場合の手順は指示書には書かない(運用者が電話の結果を見て判断する)。
- テンプレートは `template.html`(`{{名前}}` を埋める)。見た目を変えたら必ず PDF 化して 1 ページに収まることを確認する。
