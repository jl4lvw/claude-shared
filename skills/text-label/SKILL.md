# text-label — 文字だけの10面ラベル

- **余白の決まり(2026-11-13 運用者決定)**: 各面の文字は、横の面(89×48mm)の上側に 2mm 以上の余白を残して置く。端まで文字があると隣のシートへずれて印刷される(詳しくは /label-rebuild)。

園服の注文票(データ共有175・176番)で、氏名だけの2行のラベルと、サイズ・数量つきのラベルを作って印刷した手順(2026-11-06)。

## 最初にまとめて聞く(依頼に書いてあれば聞かない)
1. 元の資料: データ共有の番号、または貼り付けたテキスト
2. 1面の書き方: 例を1つ(例 `あか` / `山田　一郎` の2行、`あか　山田一郎` / `大（L）x5` / `中（M）x1`)
3. 印刷するか、するなら場所(倉庫3階・倉庫2階・本店)

## 手順
1. **読む**: データ共有は `/img` の手順で `get <番号> --variant full`。写真は横倒し・上下反転で届くので、向きを直し、原寸で切り抜いて読む
2. **起こす**: 例の書き方を守る(姓名の間の空白の有無も例どおり)。数量があれば、資料の合計欄と照合する。合わなければ止めて知らせる
3. **JSONを書く**: 置き場所は scratchpad(実名をリポジトリに入れない)
   ```json
   {"name": "サイズ数量8名",
    "labels": [["あか　山田一郎", "大（L）x5", "中（M）x1"], ["あか", "山田　花子"]],
    "line_pt": [24, 24]}
   ```
   `labels` は左の列の上から順に1面ずつ。`null` は空きの面。11面以上は2枚目へ続く。`line_pt` は行ごとの文字の大きさで、省略すると全面が同じ大きさになり、一番長い面が収まる最大(30pt以下)になる。クラスを小さく氏名を大きくするなら `[22, 30]`
4. **作る**: 実行すると PDF と確認画像ができ、PDF は Downloads と NAS の 999.一時ファイルへ置かれる
   ```bash
   python C:/ClaudeCode/.claude/skills/text-label/text_label.py make <JSONのパス>
   ```
5. **確かめる**: `preview_1.png` を Read で開き、字化け・はみ出し・並びを見る(赤い枠は確認画像だけで、PDF には入らない)
6. **報告する**: 割り付けの表を本文に書き、PDF を SendUserFile で渡す。読み取りに自信がない字は、似た字と一緒に挙げる。資料の一部しか写っていないときも書く
7. **印刷する**: 運用者が場所を指示したときだけ。送り先の確認は `--apply` なしで出せる
   ```bash
   python C:/ClaudeCode/.claude/skills/text-label/text_label.py print <JSONのパス> --place 倉庫3階 --apply
   ```
8. **結果を伝える**: `done` は印刷サーバーの完了で、紙の仕上がりは見えていない。位置の確認を運用者に頼む。ずれていたら、PWA の印刷タブの「位置調整」で直す

## 守ること
- 頼まれていない印刷はしない。試験で `--apply` を付けない(本物の用紙に出る)。動作の確認は `make` か、`--apply` なしの `print` で行う
- `--apply` は1回だけ実行する。途中で止まったら、送信済みの枚数を伝え、紙を確かめてもらってからやり直す
- 氏名は個人情報。外部 AI へ送らず、スキル・メモリ・コミットに実名を書かない
- PDF を手で印刷するときは倍率100%(「用紙に合わせる」はずれる)
- 位置は印刷サーバーのプリンターごとの調整値を読む。並びは PWA の割付と同じ列優先

## 道具
- `text_label.py`: `make` / `print`。011 の `server/labelprint.py` の面の寸法と印刷の口を使う
- `test_text_label.py`: `python -m pytest .claude/skills/text-label/test_text_label.py -q`(印刷サーバーへは送らない)
