# /sevens — 7S 検品・出荷依頼書

7S（セブンエス）の倉庫にある在庫を、**箱単位で検品して**、制服のフジ本店などへ送ってもらうための依頼書（PDF・A4・1枚）を作る。
2026-10-16 に「簡易ジャンパー 黒（G1685）S1/M2/L2/LL2/3L1＝8箱」で作った様式（案1：標準の依頼書）を、そのまま再現する。

実装: `017.Tシャツなどの注文/make_7s_request.py`（CLI あり）／テスト: `test_make_7s_request.py`

## 基本ルール

- 作るのは **PDFだけ**。7S への渡し方（LINE・メール・7S の画面など）は運用者が行う。2026-10-16 の運用者の選択で、メールの下書きは作らない。7S 宛てのメールアドレスは、プロジェクトに記録がない（聞かれたときだけ運用者に確認する）。
- **PDFは作ったら PDF ビューアで開く**（`--no-open` を付けない）。内容を運用者が確認してから渡す。Downloads にも同名でコピーされる。
- サイズ別の数は **箱数**。「S×1」「M×2」と言われたら、S1箱・M2箱として書く。迷ったら確認する。
- 手順の既定は次の5項目（運用者の指示。「商品を袋から一度出して」は、分かっているので書かない）:
  1. 箱ごとに検品してください。
  2. 不良品があれば省いてください。そのぶん箱の入数が減ってもかまいません（例：15点入りが14点になっても可）。
  3. 商品は袋に戻さず、畳んだ状態で段ボールに入れてください。
  4. 取り出した袋はまとめて、その段ボールの一番上に載せ、封をしてください。
  5. 箱単位で、上記の送り先へ発送してください。
  運用者が手順を変えたいと言ったときだけ、`--step` で差し替える（変えた内容は、確認してから反映）。
  手順を足したいときは `--extra-step`（既定の後ろに追加）。2026-10-16 のステッチハウス宛ては、「全部まとめて出荷する必要はありません。検品が終わった箱から、順に出荷してかまいません。」を6番目に足した（運用者指示）。
- **印刷仕様や納期を推測で足さない**。出荷日は、言われたときだけ `--ship-date` で入れる（空なら欄ごと出さない）。
- 7S の商品コード（`G1685-BK-S` など）は、BoxQR の `item_code_7s` から取る（表の見出しは「商品コード」）。取れないサイズは空欄になり警告が出る。**取れないときは、運用者に商品コードを確認する**。

## 手順

### Step 1: 聞き取り（番号の選択肢で・分かっていることは聞き返さない）

1. **商品**：商品コード（G番号）。同じ名前の商品が複数ある場合（例：簡易ジャンパーは G0001 OD、G1685 黒、U0019 隊員専用）は、どれか確認する。色・品番は、PDFの品名に入る。
2. **サイズ別の箱数**：例「S1、M2、L2、LL2、3L1」。
3. **送り先**：既定は「制服のフジ本店（広島県呉市中通1-1-21）」。別の送り先なら、名称・担当・郵便番号・住所・電話番号を聞き、`--dest-name` `--dest-contact` `--dest-zip` `--dest-address` `--dest-tel` で指定する（複数行で載る）。**住所・電話番号は推測せず、運用者に聞く**。ステッチハウス（担当 椋田）への送付が、2026-10-16 にあった（住所等は運用者に確認）。
4. **出荷日・手順の変更**：あれば。なければ省く。

### Step 2: PDFを作る

```bash
python "C:/ClaudeCode/017.Tシャツなどの注文/make_7s_request.py" --code G1685 --boxes S=1,M=2,L=2,LL=2,3L=1
```

オプション: `--product`（品名を直接指定）／`--destination`／`--ship-date "2026年10月20日"`／`--step "手順1" --step "手順2" …`／`--name`（ファイル名）／`--no-open`。
出力は `orders/YYYYMMDD_検品出荷依頼書_7S_<品名>.pdf`。コマンドが、PDFのパス、合計箱数、Downloads へのコピー、ビューアでの表示まで行う。

### Step 3: 確認と受け渡し

- PDFをビューアで開いたことと、内容（品名・サイズ別の箱数・合計・送り先・手順）を、運用者に短く伝える。ファイルのフルパスを、1行で示す。
- 渡し方は運用者が行う。**メールや LINE の送信は、私は行わない**。
- 運用者が「送った」と言ったら、記録を残す（Step 4）。

### Step 4: 記録

`017.Tシャツなどの注文/7S依頼/YYYYMMDD_7S検品出荷依頼.txt` に、次の項目を書く（フォルダが無ければ作る）:
送付日、渡し方（運用者の報告）、品名と商品コード、サイズ別の箱数と合計、送り先、手順に変更があればその内容、PDF の場所。
history.csv はTシャツ発注専用なので、使わない。

## 様式（変えないもの）

- タイトル「検品・出荷依頼書」、右上に日付、宛先「セブンエス 御中」。**「7S」は社内の略称で、会社名は「セブンエス」（運用者指示 2026-10-16）。書類の宛先や表の見出しに「7S」と書かない**（表の見出しは「商品コード」）。
- 項目の枠：品名／送り先（／出荷日は指定があるときだけ）。
- サイズ別の箱数の表（箱数の行、7Sコードの行、合計）。
- 見出し「作業手順」と、番号つきの手順。
- 下に、連絡先（寺下・携帯）と、制服のフジの社名・住所の枠。色は、青緑（#0f5c5c）をアクセントにする。

様式を変えたいときは、`make_7s_request.py` を直し、`発注書フォーマット集/README.md` と見本も更新する。
