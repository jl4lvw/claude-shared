# /ems-mypage — 国際郵便マイページ EMS 送り状作成

`https://www.int-mypage.post.japanpost.jp/mypage/M010000.do` を Claude in Chrome で操作する。

- 画面の観察記録（2026-10-14）: `C:\ClaudeCode\094.Chrome自動操作\docs\ems_mypage_screens.md`
- **状態: ⑤登録内容の確認まで実運用済み（2026-10-21 香港宛て商品見本で通し確認）。** ⑥印刷・⑦完了はユーザー操作のため未観察。

## 🚨 絶対ルール

1. **「登録」（⑤ 登録内容確認・登録）・送り状印刷・集荷依頼は Claude が行わない。** 「登録内容確認」画面で止まり、内容を表で報告する。
2. ID・パスワードは入力しない。ログイン画面は Chrome の自動入力済みなので、**ログインボタン（`find`「ログインボタン」→ ref クリック）を押すだけ**。入力欄が空ならユーザーに手動ログインを頼む。
3. **「危険物についてのご確認」のチェック（チェック欄は 1 つ）は、ユーザーの宣誓。** 既定は画面で止まってユーザーに頼む。**手順 0 の「最初にまとめて聞く」で確認し**、ユーザーが「危険物ではない。チェックを入れてよい」と答えた場合に限り、Claude が入れてよい（2026-10-21 ユーザー指示）。
4. 「作成途中の前回のデータがあります」ダイアログは、**ユーザーの許可なく「新しく作成する」（前回データを破棄）を押さない。**
5. 宛先・内容品・数量・金額は、ユーザーの指示にあるものだけを入力する。足りない項目は推測せず質問する。**質問は手順 0 の一覧で最初に 1 回にまとめて聞く**（小出しにしない。2026-10-21 ユーザー指示）。途中で聞いてよいのは、一覧に無い想定外の項目が画面に出たときだけ。
8. **途中で追加の質問をしたら、その項目を手順 0 の一覧に必ず追記する**（次回から最初に聞けるように。2026-10-21 ユーザー指示）。作業の報告の前に SKILL.md を直し、`.bak` を残す。
6. ブラウザの「戻る」は使わない（サイトの注意書き）。画面内の「戻る」「メニュー」を使う。
7. アドレス帳の宛先は第三者の個人情報。スキル・ドキュメント・台帳に転記しない。

## 手順

### 0. 準備
- ToolSearch で Chrome ツールを一括ロード（`select:mcp__claude-in-chrome__tabs_context_mcp,…navigate,computer,find,read_page,get_page_text,javascript_tool,tabs_create_mcp,tabs_close_mcp,form_input`）。
- **最初にまとめて聞く（ブラウザ操作の前に 1 回で）。** 指示に書かれている項目は聞かない。残りを `AskUserQuestion`（選べるもの）と本文の表（自由記入）で一度に聞く。

  | # | 項目 | 備考 |
  |---|---|---|
  | 1 | 宛先 | アドレス帳の誰か／新規（新規なら名前・会社・住所・電話） |
  | 2 | 発送種別 | EMS(物品)／EMS(書類) |
  | 3 | 販売品かサンプル・贈物か | サンプルなら「商品見本の送り方」に従う（種別=その他・無償・備考 Commercial Sample） |
  | 4 | 内容品種別 | 贈物／書類／ネット販売品／商用物品／返送品／その他（3 で決まるなら聞かない） |
  | 5 | 有償／無償 | 販売=有償、サンプル・贈物=無償（3 で決まるなら聞かない） |
  | 6 | 内容品 | 英語の品名・単価(円。無償でも 1 円以上の申告額)・品物の重量 g・個数（複数品目なら全部） |
  | 7 | 原産国 | 通常 JAPAN |
  | 8 | HS コード | 分からなければ材質・形を聞いて候補を出す（鞄=4202.92 等） |
  | 9 | 総重量（梱包後の重さ g） | 品物の重量とは別。**必須** |
  | 10 | 発送予定日 | 既定は当日 |
  | 11 | 危険物ではないことの確認 | 「危険物ではない。チェックを入れてよい」の返事をもらう（絶対ルール 3） |
  | 12 | 損害要償額 | 2 万円を超える補償が要るときだけ |
- 総額は「単価×個数」の合計で入れる（聞かない）。
- **仕向国の事前確認**: 米国宛ては、書類・100USD以下の個人間贈答品・2,500USD超のみマイページで可。2,500USD以下の物品は専用アプリ。EU 宛て IOSS(DDP) も不可。該当しそうならユーザーに伝えて止まる。

### 1. ログイン
1. URL を開き、5 秒待つ。自動入力（メール・パスワード欄の埋まり）を screenshot で確認。
2. `find`「ログインボタン」→ ref クリック → 6 秒待つ。メインメニュー（`寺下 貴之 さま (法人会員)`）になる。
3. 「作成途中の前回のデータ」ダイアログが出たら、ユーザーに「破棄するか／引き継ぐか」を確認する（絶対ルール 4）。
   - 破棄: 「新しく作成する」。**ref クリックが反映されない**ので、screenshot で位置を見て座標クリックする。
   - 引き継ぐ: 「前回のデータから作成する」。

### 2. 送り状作成（7 ステップ）
メインの「送り状作成」（`find` → ref クリック）→ 6 秒待つ。以降、各画面で 5〜6 秒待つ。

| ステップ | 操作 |
|---|---|
| ① ご依頼主 | 既定の `Seifuku-no-Fuji` が選択済み。ページ**下部**の「次へ」を押す（`find` で 2 件出る） |
| ② お届け先 | アドレス帳から選ぶ（検索・国名絞り込みあり）か、「お届け先の入力」で直接入力（英字。必須: お名前/会社名のいずれか・国名・住所2・住所3）。ラジオ選択 → 下部「次へ」 |
| ③ 内容品 | 発送種別のボタン（座標クリック）→ EMS(物品) なら内容品の入力（品名・単価・重量・個数・原産国・HS、**1 件ごとに「確定」**）→ 内容品種別 → 総額 → **危険物チェックはユーザー** |
| ④ 発送関連情報（M060800） | 発送予定日（既定=今日）・**総重量（梱包後の重さ g・必須。品物の重さとは別なので聞く）**・損害要償額（2 万円超の補償時のみ）・インボイス印刷指定（既定「規定枚数」）・**有償／無償（販売=有償、サンプル・贈物=無償）**。「+」で税関告知書・インボイス詳細（免許番号・証明番号・TAX/VAT・支払条件・インボイス番号・**備考** `shippingBean.invBiko`・差出人参照番号）が開く。郵便料金は空欄のままでよい（次画面で自動計算）→ 下部「次へ」 |
| ⑤ 登録内容の確認（M060900） | 依頼主・お届け先・内容品・種別・総額・総重量・**郵便料金**・有償/無償・備考が出る。**ここで止まる。「送り状を登録する」はユーザー** |
| ⑥ 印刷 / ⑦ 完了 | ユーザーが行う。送り状 PDF は `Downloads\<日時>EN…JP….pdf`（4 ページ）で保存される |

#### 商品見本（無償サンプル）の送り方（2026-06 以降・公式 FAQ）
- 内容品種別は **「その他」**（「商品見本」は 2026-06-01 に廃止）
- ④ の **有償／無償 = 無償**
- ④ の税関告知書・インボイス詳細の **備考 = `Commercial Sample`**
- 単価は無償でも 1 円以上の申告価格を入れる
- インボイス枚数は国によって「その他」と「商品見本」で違うことがある → 国際郵便条件表（`country_hikaku.php?cid=…`）の EMS 欄で確認し、違えば「○枚印刷する」で指定（香港=どちらも 1 枚で規定枚数のまま）

### 3. 報告
「登録内容確認」画面（または到達できた最後の画面）を `get_page_text` + screenshot で読み、宛先・種別・内容品・数量・金額・料金・重さを表で返す。「登録」ボタンは押さず、ユーザーに確認を求める。

## 待ち時間・注意

- ボタンは画像が多く、`find` でラベルが出ないことがある。screenshot で位置を見て座標クリックする。
- **ref クリックが反映されないボタンがある**: 「お届け先の入力」「送り状作成」（1回目）など。待っても変わらないときは、screenshot で位置を見て**座標クリック**に切り替える（連打しない）。
- 入力欄（品名・単価・重量・個数・総額・住所・TEL）は `form_input` で入る。国名・原産国・内容品種別のプルダウンも `form_input`（国名は value の CN 等、原産国は「JAPAN（日本）」、種別は表示名）。
- 内容品は 1 行入力したら「確定」→ 画面が再描画される（種別・総額は保持）。
- **内容品種別に「商品見本」は無い**（贈物/書類/ネット販売品(通販)/商用物品(BtoB)/返送品/その他）。「商品見本」「サンプル」と言われたら上の「商品見本の送り方」に従う。
- このサイトでは Chrome の screenshot が CDP タイムアウトで取れないことがある（2026-10-21）。その場合は `get_page_text`・`find`・`read_page`・`javascript_tool` だけで進められる（ref クリックで全画面通った）。
- ログイン画面の自動入力は、JS からは空に見える（Chrome がユーザー操作前は値を隠す）。そのままログインボタンを押せば通る。
- お届け先の直接入力（香港の例）: 住所1=Unit/階/ビル名、住所2=番地 通り名、住所3=地区名、州名=NT 等、郵便番号は空欄。敬称が不明なら氏名に Mr./Ms. を付けない。
- 登録後の確認は、メニュー →「発送履歴を見る」（お問合せ番号 EN…JP・配送状況）。
- 実績: 2026-10-15、中国宛て EMS(物品)ワイシャツ 1 件 → EN545871709JP（登録まではユーザーが実行）。2026-10-21、香港宛て EMS(物品) 商品見本 Bag 1 件（無償・550g・2,150 円）→ EN547221900JP。
- ページ遷移後に URL が `M0xxxxx.do` で変わる。`javascript_tool` の結果は URL にクエリがあると取れないことがある（その場合は `get_page_text`）。
- メンテナンス停止: 2026-10-15(木) 02:00〜05:00。
- 下書きはサーバに残り、次回ログイン時に「作成途中の前回のデータ」が出ることがある。
