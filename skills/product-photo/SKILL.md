## 2. 写真の仕上げ(Claude が作る。2 回失敗したら astra)

道具は `C:/ClaudeCode/023.商品マスタDB/tools/product_photo.py`(試験 `tests/test_product_photo.py`)。

```bash
cd C:/ClaudeCode/023.商品マスタDB
python tools/product_photo.py cutout <元写真> <作業フォルダ>/final/z_cutout.jpg   # 白い背景の白抜き(.png なら透明)
python tools/product_photo.py square <元写真> <作業フォルダ>/final/d_chest.jpg    # 正方形・商品を中心・1200 角(回転させない)
python tools/product_photo.py check <作業フォルダ>/final --out <作業フォルダ>/check [--navy]
```

- `cutout` は白い背景(撮影台・白い布)か、明るい無地の背景(縁の色に近い所を消す)の写真向け。**紺の布の背景で撮った写真**は先に `tools/navy_backdrop.py` の `to_white()` で白にする
- `check` は 1200 角・2MB 以内かを見て、`red_*.jpg`(消した背景を赤)・`edges_*.jpg`(四隅と上下の中央の拡大)・`sheet.jpg`(一覧)を作る。
  **赤の画像と縁の拡大を Read で必ず見る**。紺の布の背景を消した明るい商品は `--navy` で縁に残った紺の割合も見る(0 に近いこと)
- 写真の決まり(運用者決定・省略しない):
  - 背景はすべて消して白にする。商品は欠けさせない。縁の外に紺・灰色の細い帯を残さない
  - 切り抜きは画素ごとに背景を判定する。四角形で切るのは色で分けられないときだけ(使ったら報告に書く)。トップ画像と末尾の白抜きは必ず画素ごと
  - **正方形の元写真を回転させない**(四隅に白い三角が出る)。逆さ・横向きだけ 90 度単位で直す
  - 寄りの写真が切れるなら、切らずに白い余白で正方形にする。商品は写真の中心に置く
  - 明るさ・色味を全部の写真でそろえる。商品の色は元写真のまま
  - 形・色・明るさを変える処理だけにし、画像を作り出す AI で商品写真を描き直さない(プリントの文字が変わる)
- **失敗の数え方**: 運用者の指摘、または Claude が拡大して見つけた問題で作り直したら 1 回。**同じ写真で 2 回作り直しても直らなければ astra に頼む**(下の「astra に頼む」・雛形 `templates/task_photos.md`)。粘らない(G2250 で何十回も失敗した)

## 3. 着用画像(Tシャツ・最初から astra)

Claude には作れないので、最初から astra に頼む。雛形 `templates/task_wear.md` を埋める。

- **胸のマークは着た人の左胸 = 前から見て右**(luna は反対の胸に付けた)
- **袖のプリントは袖の外側の面**: 真後ろ・真正面からは袖の丸みに沿って回り込み、端の半分ほどが斜めに細く見えるだけ
- **袖のプリントは実物の比率**: 袖口寄りで、袖の長さの半分ほど。袖いっぱいに広げない
- 顔は写さない(あごから下)・短髪の男性・直立・明るい無地の背景・茶色系のチノパン
- **名前と顔のあるモデルで作るとき(2026-10-27〜)は雛形 `templates/task_wear_model.md`**。モデル帳 `a_browser_data/rakuten_new_item/_models/<フォルダ名>/`(profile.md と顔・全身の見本)を `ref_model/` へ写して渡す。モデルの名前はすべてひらがな(女性「みゆき」= `_models/miyuki/`・男性「りょうすけ」= `_models/ryosuke/`(爽やか・172cm)・「だいすけ」= `_models/daisuke/`(ソフトモヒカン・ひげ・178cm)(2026-10-28〜))。髪で背中のプリントを隠さない。出来たら見本の顔と並べて同じ人か確かめる
- 手本の姿勢 `G1635_photo/ref_wear/pose_back.jpg`・書き方 `G1635_photo/ref_wear/example_prompt_g1591.md` を `ref_wear/` に写して渡す
- 出来たら、元写真のプリントと見比べる(文字・胸の位置・袖の大きさと見え方)。おかしければ `templates/fix.md` で直しを頼む(1 回 4〜5 分)
- **プリントの大きさは身長を物差しにして cm で確かめる**(2026-10-28 G1690): 人の高さ(髪・靴込み。だいすけ 178cm → 182.5cm)の画素から 1cm の画素数を出し、プリント・襟の大きさを cm にして**運用者が実物を測った値**(G1690: 胸のマーク 9cm・襟の開き 16cm・背中の翼 30cm)と比べる。**絵の中の服の部分(身幅・襟)を物差しにしない**(astra は襟を約 20cm と広く描いていた。身幅の比で判断して 0.7 倍に縮めたら小さすぎた)。実物の寸法が無ければ運用者に測ってもらう。直しの依頼には cm と画素の両方を書く(襟も細くできる。4 枚で 10 分ほど)。縮めると襟の縁にギザギザ・旧プリントの消し残りが出るので拡大して見る

## 3b. 名前付きモデルの着用画像とトップ画像(女性モデル・2026-10-27 G1051 で決定)

顔と名前のあるモデル(女性「みゆき」・男性「りょうすけ」「だいすけ」)で着用画像を作り、それでトップ画像を作るときの決まった作り方。

道具は `C:/ClaudeCode/023.商品マスタDB/tools/wear_model_photo.py`(試験 `tests/test_wear_model_photo.py`)。

### 1) 着用画像を astra に頼む
- 雛形 `templates/task_wear_model.md`。モデル帳 `a_browser_data/rakuten_new_item/_models/<フォルダ名>/` の `profile.md` と顔・全身の見本を `ref_model/` へ写して渡す
- 向きは 4 方向以上: 紺(濃い色)は 正面・真後ろ・斜め前・斜め後ろ、白(薄い色)は 正面・真後ろ。名前は `wear_<色>_<front|back|front45|back45>.jpg`
- 下の服は、シャツと溶けない色: 濃いシャツには白い細身のパンツ、白いシャツには濃い青のデニム(道具が裾を測れる色)
- 背景は明るい灰色(灰青)の無地のスタジオ。**髪で背中のプリントを隠さない**

### 2) 切り抜く(Claude が道具で・画素ごと)
```bash
cd C:/ClaudeCode/023.商品マスタDB
python tools/wear_model_photo.py cutout <作業フォルダ>/final/gray_bg/wear_navy_front.jpg --jpg <作業フォルダ>/cut/wear_navy_front.jpg --png <作業フォルダ>/final/png/wear_navy_front.png
```
- astra の出来上がり(灰色の背景)は `final/gray_bg/` に残す。`--jpg` は白い背景の版、`--png` は透明の版(トップ画像に使う)
- **背景の明るさの変化が強い(床が明るい)とき・黒いシャツのとき**は `--strong-bg` を付ける(G1690。付けないと灰青が大きく残った)。紺のシャツには付けない(紺の明るい所が消える)
- 背景は縁の色から場所ごとに推定して消す(グラデーション・むらに合う)。腕と胴の間・脚の間の細いすき間も消し、紺の上のプリント(錨・線)と白い服の影は残す
- **赤い背景に重ねて確かめる**: 灰色の残り(すき間)・欠け(錨・線の縁・白い服の影)を拡大して見る

### 3) 商品用の着用画像に切る
```bash
python tools/wear_model_photo.py crop <作業フォルダ>/cut/wear_navy_front.jpg --png <作業フォルダ>/final/png/wear_navy_front.png --shirt dark --out <作業フォルダ>/final/wear_navy_front.jpg
```
- **パンツは Tシャツの裾の下 10cm ほどまで**(運用者指定)。頭のてっぺんから裾までを 68cm(身長 158cm の目安)として 1cm の画素数を出す
- 頭の上に 30 画素の余白・体の真ん中(人の画素の重さの真ん中。手の先に引っぱられない)で正方形に切り、1200 角へ拡大(G1051 は 1.12〜1.17 倍)
- `--shirt` は 紺など濃いシャツ=`dark`、白など明るいシャツ=`light`。明るいシャツはデニムか黒のパンツで裾を測る。ほかの色のパンツは止まるので `--hem <裾の y>` で渡す

## 4. トップ画像(Claude が道具で作る)

```bash
cd C:/ClaudeCode/023.商品マスタDB
python tools/product_photo.py top-white --config <作業フォルダ>/photo.json   # 白い背景の版(Tシャツ・タオル・ワッペン)
python tools/product_photo.py top-wear  --config <作業フォルダ>/photo.json   # 着用画像の版(Tシャツ)
```

- **Tシャツのトップ画像(1 枚目)は着用画像の版**(手本 楽天 G1591・G1699 の 1 枚目)。白い背景の版は 2 枚目に置く
- `top-wear` は背中の着用画像から Tシャツとプリントの位置を測り、**プリントが欠けず・左下の前の着用画像に重ならず・シャツの左端が左の文字の列より右**に来る一番大きい倍率を選ぶ(上限 1.35)。
  出力の `scale`・`print_on_canvas`・`warnings` を見て、気に入らなければ photo.json に `"scale"`・`"offset"` を書いて上書きする。
  上書きした値でもプリントが欠ける・艦名や前の着用画像に重なるときは、画像を出さずに止まる(理由が出る)
- プリントは近い文字・線をまとめて測り、一番大きいまとまり(背中の図柄)を基準に置く。袖のプリントなど離れたまとまりは、画面から欠けないかだけを見る(欠けると `warnings` に出る)
- 前の着用画像は輪郭で白抜きして左下に重ねる(四角いまま貼ると後ろの人の腕を隠す)。胸のマークと袖のある側(前から見て右)に寄せて切り出す
- 文言の誤字は Read で拡大して確かめる

## 6. 楽天の写真を差し替える(既存商品)

0. **並びの案は楽天の今の写真から作る**(2026-10-27 G1051)。Yahoo!・本店は写真の組が楽天と違うことがある(G1051 は Yahoo! 21 枚・本店 25 枚・楽天 20 枚)。
   `photo_inspect.py <G番号>` で 3 モールを並べ、**楽天に無く本店・Yahoo! にだけある写真**を探す。展開で本店・Yahoo! は楽天の並び(楽天だけの写真を除く)で丸ごと置き換わるので、そのままでは消える。
   残すなら楽天にも新しい写真として足す(G1051 のキッズ 3 枚)。Yahoo! の写真の元の大きさ(1200 画素)は `https://item-shopping.c.yimg.jp/i/z/<画像名>` で取れる(`/i/l/` は 600 画素)。
   楽天の上限は **20 枚**(楽天だけの写真を含む)。案はアーティファクトで「新規・今のまま・楽天だけ・外す・楽天に無い」に分けて見せ、運用者に決めてもらう
1. `<作業フォルダ>/replace/spec.json` を書く(形は `tools/rakuten_photo_replace.py` の冒頭)。今の写真はすべて `keep` か `remove` に書く。1 枚目は新しいトップ画像・白抜きは末尾。楽天だけの写真(`/tj/`・`/ranking/`)は `keep`
2. 計画を作る(読み取りだけ):
   ```bash
   cd C:/ClaudeCode/023.商品マスタDB && python tools/rakuten_photo_replace.py build --spec <作業フォルダ>/replace/spec.json
   ```

同じ ASIN の LCL 用 SKU が古い画像のまま、というのが疑い(未確認)。原因が分かるまでは:
- **まず 1 件(または同じ ASIN の子と LCL 用の 2 件)だけ**を申請して書き、**数時間後に読み直して戻らない**ことを確かめてから、残りを申請する
- 戻る場合は、全件を書かずに止めて運用者に報告する(書いても戻るなら、承認の手間と Amazon への送信が無駄になる)
- **2026-10-28 の読み直しで分かったこと**: NV-S は翌日には 9 枠とも新しい画像で定着し、売り場も新しくなった。Amazon は「書いた直後は新 → 数分で元に戻って見える → 数時間〜翌日に新で定着」と動く。**書いた直後に戻って見えても失敗と決めない**。翌日に読み直して判断する
- 同じ ASIN の LCL 用 SKU は、子を書けば一緒に新しい画像になった(LCL への書き込みは要らない可能性がある)
- 今の道具は書いた直後の読み直しで止まる(10/28 申請 509 は LCL 用 NV-M で止まった)。翌日に読み直し、新しければ残りを申請し直す(済んだ SKU は build が外す)。直後の確かめを「翌日の確かめ」に変えるかは未決(詳細はメモリ project_amazon_photo_revert_pending)

## photo.json

パスは photo.json のフォルダからの相対で書ける。`out_dir` に出す。`out` の省略時は Tシャツ: 着用画像の版 `a_main.jpg`・白い背景の版 `a_main_white.jpg` / タオル・ワッペン: `a_main.jpg`(2 つが同じ名前なら止まる)。

```json
{
  "g": "G1635",
  "kind": "tshirt",
  "out_dir": "final",
  "top_white": {
    "out": "h_main_white.jpg",
    "cutout": "final/z_cutout.jpg",
    "title": ["記念Tシャツ(IPD2021)", "護衛艦かが"],
    "sizes": ["S", "M", "L", "LL", "3L"],
    "fabric": "ドライ生地",
    "chest": "final/d_chest.jpg",
    "chest_label": "胸元プリント"
  },
  "top_wear": {
    "out": "a_main.jpg",
    "back": "final/f_wear_back.jpg",
    "front": "final/g_wear_front.jpg",
    "size_label": "S－3L",
    "name": ["護衛艦かが", "IPD2021"]
  }
}
```

| キー | 意味 |
|---|---|
| `kind` | `tshirt` / `towel` / `wappen` |
| `top_white.cutout` | 商品の白抜き(白い背景の JPEG か透明の PNG) |
| `top_white.title` | Tシャツ: 行の配列 / タオル・ワッペン: 艦名の文字列 |
| `top_white.label` | タオル・ワッペンの見出し(省略時 タオル `["綿 100%", "スポーツタオル"]`・ワッペン `["日本製", "ワッペン"]`) |
| `top_white.size_text` | タオル・ワッペンの右下(`サイズ：約 110×35cm`・`サイズ：直径 10cm`) |
| `top_white.chest` / `chest_circle` | Tシャツの右下の丸に使う胸の寄り。丸の位置は測る(`[cx, cy, r]` で上書き) |
| `top_wear.dry` / `dry_sub` | 青の「DRY」「吸汗速乾」(既定 true。ドライ生地でなければ false) |
| `top_wear.name` | 右下の白い明朝。`["護衛艦かが", "IPD2021"]` か `[["護衛艦かが", 92], ["IPD2021", 66]]` |
| `top_wear.fabric` | シャツの色。既定 `navy`(紺)。黒いシャツは `black`(G1690) |
| `top_wear.inset_chest` / `chest_circle` | 左下を前の着用画像ではなく**実物の胸の寄りの丸**(「胸元プリント」)にする。着用画像の胸の小さい文字が崩れるとき(G1690 で運用者指示)。丸の位置は `[cx, cy, r]` で詰める。**寄りの写真は正面から撮ったものに限る**(斜めは運用者に差し戻された)。斜めしか無ければ `product_photo.py front-circle IN OUT` で正面の形に直し(黄色い輪に楕円を当てて円に戻す)、出力の `chest_circle` を使う |
| `top_wear.scale` / `offset` / `max_scale` / `inset_side` | 倍率・位置の上書き / 倍率の上限(既定 1.35)/ 前の着用画像を寄せる側(既定 `right`) |

共通の素材(海上自衛隊のマーク)は `023.商品マスタDB/assets/product_photo/jmsdf_mark.png`。
