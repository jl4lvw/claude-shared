# mw — 待ち受けモード(`/m watch` の短縮)

スマホから打ちやすいように `/m watch` を短くしたもの。**`/m`(1回だけ処理)とは別のスキル**で、このスキルを呼んだセッションは relay の待ち受け役になる。

## このファイルを読んでいる Claude へ

1. `.claude/skills/message-check/SKILL.md` を **Read** で読み込み、末尾の「待ち受けモード」節(W0〜W6)に従う。Skill ツールで `/message-check` や `/m` を呼ばない(スキル連鎖禁止)。
2. **最初に引数を見て分岐する**(前後の空白は無視し、大文字小文字は区別しない。完全一致):
   - `stop`(`/mw stop`) → W0 の確認には流さず、**W6(解除)だけを行う**(直接入力かどうかだけ確かめる)。
   - 引数なし(`/mw`) → W0(入る前の確認)を必ず行い、満たせば W1(見張りの起動)へ。直接入力でない・この端末が未対応・作業の途中・常駐GUIが有効、のどれかなら arm せずに終える。W1 の 4a のとおり、**見張りを起動したあとに、セッション名が規定の書式か確認し、違えば名前を決める**(新しいセッションで `/mw` が最初の入力のときも対象。`/mw stop` は対象外)。
   - それ以外(`/mw 2828` など) → 何も実行せず、「使い方: `/m`(1回だけ処理) / `/mw` または `/m watch`(待ち受け) / `/mw stop`(解除)」と 1 行返す。
4. 待ち受けセッションは Sonnet 5.5・エフォート「中」を推奨(設定はセッション側。本文「役割分担」参照)。
5. 待ち受けに入ったら、本体の規則どおり自分では relay を処理しない(見張りの起動・処理役の呼び出し・ack だけ)。
