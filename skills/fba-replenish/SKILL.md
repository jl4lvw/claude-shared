# /fba-replenish — FBA へ補充する商品を選ぶ

**読み取りだけのスキル。** 022 の在庫・カート・必要数・7S専用の印は変えない。
カート(ピッキングリスト・7S カート)はブラウザの中にだけ保存されるので、Claude からは入れられない。
選んでカートへ入れるのは運用者が PWA で行う。

## 判定ルール(2026-10-27 運用者と決定)

判定の本体は `022.Amazon在庫PWA/pwa/picking-select.js` の `pickReplenish`(PWA の「🚚 FBA補充」タブと同じもの)。
**このスキルの中に判定を書き直さない**(PWA とずれるため)。変えるときは picking-select.js とそのテストを直す。

| 区分 | 条件 | 送る数 | PWA での最初の選択 |
|---|---|---|---|
| A 必ず補充 | 30日売上 × 1.0 − (FBA在庫 + 入荷中) > 0 | 売上ベースの不足 | 選択あり |
| A の「設定数まで+N」 | A の商品で、FBA必要数までまだ足りない | 足すかは人が選ぶ(ボタン) | 足さない |
| B 要確認 | A でなく、FBA必要数 − (FBA在庫 + 入荷中) > 0 | 必要数ベースの不足 | 選択なし |
| 「設定数が多すぎる疑い」 | 必要数 > 30日売上 × 3(売上0で必要数ありも含む) | — | 印だけ |

- **補充元**: 「7S専用」の印(DB v61 `source_7s_only`)があれば 7S、無ければ本店。本店の在庫数は見ない(大半が未入力のため)
- **7S から送る数** = min(不足, 7S在庫 − 1)。FBM 用に 1 個残す。0 なら「送れない」
- **対象外**: 親SKU・販売終了・手動で除外・Disabled・2SKU の LCL役・FBA運用でないもの(FBM 運用中を含む)
- 定数は picking-select.js の `REPLEN_SALES_FACTOR`(1.0)・`REPLEN_OVERSET_RATIO`(3)・`REPLEN_KEEP_7S`(1)

## 手順

### 1. 候補を出す

```bash
cd C:/ClaudeCode && python .claude/skills/fba-replenish/fba_replenish.py
```

- 本番の 022 (`http://127.0.0.1:8090/inventory/all`) を GET で読むだけ
- 出力は `C:/tmp-ai/fba_replenish/<日時>/` に `report.md`・`result.json`・`cart_import_hq.json`
- `--top N` で表の件数、`--include-b` で取り込み JSON に B も入れる、`--input <json>` で保存済みの一覧から判定

### 2. 本文で報告する

`report.md` の内容(件数・A の表・B の上位・送れない・7S専用の候補)を**本文に貼る**(ファイルを指すだけにしない)。
商品名は表に出ているので、G番号だけで書かない。

報告で触れること:
- A の件数・個数(本店から / 7S から)
- B は「設定数が多すぎる疑い」の件数も添える(必要数の見直し候補)
- 「送れない」がある → 7S への補充(発注)が必要
- 「7S専用の印を付ける候補」がある → 本店に置かない商品か運用者に確かめてもらう
- `⚠️ サーバーが「7S専用」の印にまだ対応していません` と出たら、022 サーバーが v61 前の版。全件を本店からとして判定している

### 3. カートへ入れてもらう

運用者に案内する(Claude はやらない):

1. `https://sfuji.f5.si/amzinv/` → ピッキング画面の「🎯 ピッキング対象選定」→「🚚 FBA補充」タブ
2. A は選択済み。B は見て必要なものだけ選ぶ。A の「+N 設定数まで」で設定数まで足せる
3. 「7S専用にする/外す」で補充元を切り替えられる(すぐ保存され、表が取り直される)
4. 「🛒 カートへ追加」→ 本店分はピッキングリスト、7S専用の分は 7S カートへ(どちらも数量は上書き)

本店分だけなら、`cart_import_hq.json` の中身をピッキングリストの「📥 JSON取り込み」に貼っても入る(mode は replace)。

その後の FBA 納品は `/amz-inbound`。

## 7S専用の印

- 本店に置かず 7S にだけ在庫がある商品に付ける。付け外しは PWA の FBA補充タブの各行のボタン、
  または `PATCH /inventory/{sku}/source-7s-only` `{"source_7s_only": true|false}`(Origin 検査のみ・PIN なし)
- Claude が API で付けるのは運用者が商品を指定して頼んだときだけ(書き込みなので、付ける一覧を見せて承認を得てから)
