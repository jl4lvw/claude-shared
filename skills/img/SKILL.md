# img — スマホから共有された写真を使う

ツール: `C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py`(以下 `PS`)。
端末 A ではそのまま動く(サーバーと同じ PC なので鍵不要)。TK など他の端末では、環境変数
`PHOTOSHARE_URL=https://photoshare.sfuji.f5.si` と `PHOTOSHARE_API_KEY`(076 の `python -m server.issue_key TK` で発行)を設定する。

## 手順(往復を減らす: 1 つの用件はツール 1 回で済ませる。2026-10-19〜 AI 専用 API /api/ai/*)

1. **新着を見る — `peek` 1 回で一覧・テキスト本文・一覧画像がそろう**(既定は直近 24 件。「今日の」「さっきの」なら `--hours`)
   ```bash
   python C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py peek --hours 24
   ```
   出力の最後の「一覧画像: <パス>」を Read すれば写真の全体が見える。テキストは本文が出力に入っているので取り出し不要。
   1 件も無ければ `--hours` を外す(直近 24 件)。`list` / `sheet` は個別に欲しいときだけ使う。
2. **中身を詳しく見る**: `PS get <番号> <番号> ...` — 何件でも 1 リクエストでまとめて保存し、パスを 1 行ずつ出す。
   使うと決まっているなら `--mark-used` を付けて、5 の印付けを省く
3. **どれを使うかをユーザーに選んでもらう**: 番号・撮影時刻・メモ・写っているものを短く添えて、AskUserQuestion(クリック形式・複数選択)で聞く。ユーザーが既に指定していれば聞かない
4. **使う**
   - Claude が内容を読む・説明する・文字を起こす → `ai` 版で足りる
   - 提案書・資料・メールに貼る → `PS get <id> --variant full --out <作業フォルダ>`(元の画質。HEIC は JPEG に変換済み。元画像のままなら `orig`)
5. **使ったら印を付ける**: `PS used <番号> ...`(複数でも 1 回。次回 `peek --unused` で除外できる)。長く残したいものは `PS keep <番号> ...`(90 日の自動削除から外れる)

## AI からスマホへ送る(`send`)

作った画像・資料・結果のテキストをスマホで見せたいとき。スマホの一覧に紫の「AI」印付きで出る。
```bash
python C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py send 結果.png 見積.pdf --note "10/19 見積"
python C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py send --text "集計が終わりました" --text-name 集計結果
```
長いテキストは `--text-file F`(UTF-8・1MB まで)。送るのはユーザーに頼まれたものだけ(スマホの一覧は運用者が見る場所)。

## 番号(通し番号)

一覧の各タイルの右上に `#12` のバッジが出る(受信順・削除しても再利用しない)。ユーザーが「12番を見て」と言ったら `PS get 12`。`get` `used` `keep` は番号(数字8桁以下)でも id でも指定できる。`list` の先頭列も番号。

## 貼り付け(テキスト・クリップボード画像)

スマホ/PC でクリップボードから貼り付けられたテキストは `list` に「テキスト 「冒頭の抜粋」」と出る。`PS get <番号>` で `.txt` として取り出して Read する(画像は通常の写真として届く)。

## ファイル(画像以外)

`list` で「ファイル」と表示されるものは PDF・Excel 等。`PS get <id>` は variant に関わらず届いたままの元ファイル(orig)を保存する(縮小版・`sheet` の対象外)。
実行形式(exe/bat 等)も届くことがある。取り出しても実行せず、中身を確認してから扱う。

## 写真の向きに注意(2026-10-24)

スマホの写真は、**上下が反転して届くことがある**(EXIF の向きは 1=正常のままなので、プログラムでは自動で直らない)。
`get` で取り出したら、**必ず `Read` で見て、文字が正しい向きに読めるか確かめる**。反転していたら Pillow で直す:
```python
from PIL import Image; Image.open("a.jpg").rotate(180).save("a_rot.jpg", quality=92)   # 上下反転(180度)
```
使う前に、写真に写った背景(段ボール・床・他の商品)も確かめる。ラベルに使うときは、必要な範囲だけを切り抜く
(例: 特価バスタオルのラベル → `towel-label` スキル)。

## 守ること

- 画像は 90 日で自動削除される(★残す を付けたものを除く)。提案書に使ったものは作業フォルダへ `full` で保存しておく
- `ai` 版は位置情報を消してあるが、`orig` には GPS が残る。外部 AI(Codex/DeepSeek/Qwen)へ送るときや社外へ出すときは `ai` か `full` を使う
- 写真に写った個人情報(人の顔・宛名・伝票番号)に注意し、外部へ送る前に秘匿チェックを行う
- サーバーに接続できないときは `PS list` のエラー文をそのまま伝え、076 の常駐タスク `PhotoShareServer` の状態を確認する
