# img — スマホから共有された写真を使う

ツール: `C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py`(以下 `PS`)。
端末 A ではそのまま動く(サーバーと同じ PC なので鍵不要)。TK など他の端末では、環境変数
`PHOTOSHARE_URL=https://photoshare.sfuji.f5.si` と `PHOTOSHARE_API_KEY`(076 の `python -m server.issue_key TK` で発行)を設定する。

## 手順

1. **新着を確認する**(既定は直近 24 時間。ユーザーが「今日の」「さっきの」と言えばそれに合わせる)
   ```bash
   python C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py list --hours 24
   ```
   1 枚も無ければ `--hours` を広げるか、`list --limit 30`(期間指定なし)で直近を見る。
2. **中身を見る**
   - 数枚なら: `PS get <id> ...`(既定 `--variant ai` = 長い辺 1568px・位置情報なし)で取り出し、出力されたパスを Read で見る
   - 多いときは: `PS sheet --hours 24` で番号付きの一覧画像を 1 枚作り、それを Read して全体を見る(読み込み 1 回で済む)
3. **どれを使うかをユーザーに選んでもらう**: 番号・撮影時刻・メモ・写っているものを短く添えて、AskUserQuestion(クリック形式・複数選択)で聞く。ユーザーが既に指定していれば聞かない
4. **使う**
   - Claude が内容を読む・説明する・文字を起こす → `ai` 版で足りる
   - 提案書・資料・メールに貼る → `PS get <id> --variant full --out <作業フォルダ>`(元の画質。HEIC は JPEG に変換済み。元画像のままなら `orig`)
5. **使ったら印を付ける**: `PS used <id> ...`(次回 `list --unused` で除外できる)。長く残したいものは `PS keep <id>`(90 日の自動削除から外れる)

## 守ること

- 画像は 90 日で自動削除される(★残す を付けたものを除く)。提案書に使ったものは作業フォルダへ `full` で保存しておく
- `ai` 版は位置情報を消してあるが、`orig` には GPS が残る。外部 AI(Codex/DeepSeek/Qwen)へ送るときや社外へ出すときは `ai` か `full` を使う
- 写真に写った個人情報(人の顔・宛名・伝票番号)に注意し、外部へ送る前に秘匿チェックを行う
- サーバーに接続できないときは `PS list` のエラー文をそのまま伝え、076 の常駐タスク `PhotoShareServer` の状態を確認する
