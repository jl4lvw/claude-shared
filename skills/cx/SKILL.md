# cx — デバッグを Codex へ丸投げする（Claude のトークンを最小にする）

## 目的
ユーザーの依頼原文と機械が集めた情報（規約・メモリの写し）を、Codex の新しいセッションへ渡す。完了後に Claude が扱うのは、機械検査の受領書（12 行以内）だけ。
前提（ユーザー決定）: Claude と ChatGPT は見られる情報も実行権限も同じ。依頼は短く、分析を含めない。結果は要約だけで、Claude は本文を読まない。

## 手順
1. 対象 project が原文だけで一意に決まらない場合だけ、`ls` の候補を AskUserQuestion で確認する。**調査はしない**
2. 依頼の**原文を一切言い換えず**（引用符・改行・空白も保持）、project の外の UTF-8 ファイル `C:/tmp-ai/cx_request_<YYYYmmdd_HHMMSS>.txt` に Write する
3. 次を **1 回だけ**実行する
```bash
python "C:/ClaudeCode/.claude/tools/cgd_cx.py" new --project "<対象フォルダ>" --request-file "<上のファイル>"
```
既定では、Codex は `plan.md`（再現手順・完了条件・触る範囲）を書いて**ユーザーの OK を待つ**。`--go` は付けない。依頼が簡単で範囲・完了条件が明確なときだけ `new --go`（plan は残し、OK を待たずに進める）
4. 成功したら、標準出力の **2 行だけ**をコードブロックでそのままユーザーへ示す。説明を足さない（ユーザーがそれを Codex デスクトップの新しいセッションに貼る）
5. ユーザーが Codex の完了を知らせたら、示された run ディレクトリ（貼付文の 2 行目の `request.md` の親）に対して実行する
```bash
python "C:/ClaudeCode/.claude/tools/cgd_cx.py" receipt --run "<run ディレクトリ>"
```
6. 標準出力の受領書だけをそのまま伝える。**`request.md`・`plan.md`・`result.md`・`detail/` の本文は読まない**
7. 「依頼の修正」は常に未確認。ユーザーが `plan.md` の完了条件と `result.md` を自分で確認する

`receipt` の追加の引数: `--timeout <秒>`（検査の打ち切り）・`--checks <JSON>`（追加の検査コマンド）。状態だけを見るときは `status --run <run ディレクトリ>`

## 受領書の読み方
- 「機械検査: 合格」「変更なし（検査対象なし）」は、**依頼が達成された証明ではない**
- 「無視 N 件」は、常時更新される計測ファイル（`.hq/`・`.ctx/`・`.claude/incidents/` の自動計測・SQLite の `-shm` `-wal` `.db-journal` など）を判定から除いた件数
- 「不安定 N 件」は、他のプロセスが書き換え中で比べられなかったファイル。対象外の不安定は判定に入れない
- 「対象外・保護領域」の変更は、他のセッションの作業の可能性がある。先頭 3 件のパスが出る（全件は受領書 JSON）

## 要確認の場合
次の選択肢だけを示す: ユーザー自身が `result.md` を読む／`/lv3a` または `/lv3a --roster lv7` で差分をレビューする。
**restore は未提供**（他のセッションの変更まで巻き戻す恐れがあるため保留）。反映・デプロイ・`/g-ul` は別手順。

## 終了コード
| コマンド | exit | 意味 |
|---|---:|---|
| new | 0 / 1 / 2 / 3 | 成功 / 依頼入力の不備 / project・base の不備 / 生成・Lv0・走査の失敗（対象が大きすぎるときも 3。`--project` を狭くする） |
| receipt | 0 / 20 / 1 / 2 | 合格または変更なし / 要確認 / 前提の不備 / state の project・repository の不備 |
| status | 0 / 1 | 表示成功 / 前提の不備 |

## ガードレール（機械が守る）
- 原文・run・context・受領書を削除・上書きしない（`receipt` の再実行は新しい世代を足す）
- 標準出力・標準エラーに、依頼原文・秘密の値・検査ログ・result の本文を出さない
- `.claude/` を変更しない。対象は git リポジトリの内側のサブフォルダ（約 3 万ファイル・500MB 以内）
- Claude は、依頼を調べない・要約しない・`request.md` `result.md` `detail/` を読まない・削除しない
