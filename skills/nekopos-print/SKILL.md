# nekopos-print — ネコポス用紙への印刷

「ネコポス」で印刷を頼まれたらこの手順。**印刷は依頼どおり実行してよい**（承認画面は不要）。

## 手順

1. PDF を用意する。データ共有の番号なら `/img` で `python C:/ClaudeCode/076.写真共有PWA/tools/photoshare.py get <番号>`（パスが出る）
2. 実行（マスク除去→左1mm→白紙検査→実寸印刷→印刷ログ確認まで 1 コマンド）:
   ```bash
   cd C:/ClaudeCode && python .claude/skills/nekopos-print/nekopos_print.py "<PDFのパス>"
   ```
   先に確認だけなら `--dry-run`（印刷しない）。
3. 出力の「印刷されました…ページ数: N」を確認して報告する。**紙の実物の位置は見えない**ので「紙で確認してください」と添える。

## 罠（2026-10-23 実害あり）

- B2 の送り状PDFには `$Mask0-0$` 等のフォーム(Widget)が付いており、Acrobat 以外(SumatraPDF・MuPDF)では
  **紙面全体が白く覆われ、白紙で出る**（用紙2枚を無駄にした）。スクリプトが取り除く。
- 「印刷サービスが完了と言った」は内容の証拠にならない。スクリプトは印刷前に描画してインク量を検査し、白紙なら止まる。
- 位置は 047 の `neko6` プロファイルと同じ（`offset_mm=(-1,0)`・100%・noscale。実物確認済み 2026-10-17）。
  ずれたら `nekopos_print.py` の `OFFSET_MM` を 1mm 単位で調整する。
- 2ページ目が 3 面だけでも、紙は 1 枚消費する（使用済みの面を避けたいときは先にユーザーへ聞く）。
- プリンターは Windows 名 `*ネコポス`（`[倉庫3F]ネコポス`・RICOH SP 4500）。

## 関連

- 047 の B2 直接発行は自動で同じ設定で印刷する。これは**外から届いたPDF**（ふるさと納税・データ共有など）を出すための手順。
